# Quarantined results — degenerate configuration (2026-06-01)

**Status: INVALID. Do not cite these numbers as OIDA results.**

This directory holds the result artifacts of a benchmark run that was a
**degenerate configuration**: the scored `v0 retrieve` path ran with the entire
epistemic apparatus inert, unpopulated, or stripped. What was actually measured
was `similarity -> regime-gravity multiplier (a time-blind class constant) ->
compose` — i.e. a slightly re-weighted vector search, not OIDA's thesis.

Because the OIDA Engine's machinery did not run, **both** headline conclusions of
the original run are unsupported and retired:

- the claim that OIDA is "strong on time-/truth-aware retrieval" (the machinery
  did not run), and
- the claim that "the temporal thesis is not supported" (the thesis was never
  exercised).

A null result on a degenerate configuration is not a null result on the
architecture.

## Why these files are here (and not deleted)

Per IC decision, the triggering run is **quarantined, not deleted**. The artifacts
are **moved** (history preserved) so they remain available for the
H8 / deployment-sensitivity record, while being removed from the live results
paths so they cannot be mistaken for, or re-cited as, valid OIDA performance.

- These numbers are **INVALID**.
- **Do not cite** them as OIDA results.
- They are retained only as the record of a **degenerate** deployment.
