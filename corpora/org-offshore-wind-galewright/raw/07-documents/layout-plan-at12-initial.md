# Marrowbank — Initial Array Layout (AT-12)

**Date:** May 10, 2025
**Document type:** Array layout plan (initial)
**Owner:** Ravi Menon, Head of Engineering
**Status:** Initial layout — superseded by the AT-15 selection (see turbine-selection memo)

---

## 1. Basis

This initial array layout for Marrowbank is built around the **Aeolus AT-12 (12 MW)** turbine, the most mature large machine available at the time of writing. It establishes a working layout for early EIA scoping, met-ocean planning, and cost estimation, pending the turbine options appraisal.

## 2. Layout

- **Turbine model:** Aeolus AT-12, 12 MW.
- **Number of turbines:** **58** (58 × 12 MW ≈ 696 MW, meeting the ~700 MW target).
- **Rotor diameter:** ~220 m.
- **Spacing:** prevailing-wind-aligned grid, spacing chosen to keep array wake losses within the resource assessment's loss budget.
- **Foundations:** monopile, suited to the 28–46 m depths across the array.
- **Array cabling:** inter-array strings collecting to an offshore substation platform.

## 3. Status and caveat

This is the **initial** layout and is explicitly provisional. Engineering's view is that a larger machine (the AT-15) may give a materially better layout — fewer turbines, fewer foundations and cables, better LCOE — if the OEM can confirm delivery. A turbine options appraisal is in hand. **If the project moves to the AT-15, this 58-turbine AT-12 layout will be superseded** and should not be used for the consent envelope or the cost basis. Treat this document as the starting point, not the decided array.
