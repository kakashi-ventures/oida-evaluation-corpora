# Marrowbank — Project Programme (Initial, COD 2029)

**Date:** March 1, 2025
**Document type:** Project programme (initial baseline)
**Owner:** Eleanor Vance, Project Director
**Status:** Initial baseline programme — later superseded by the revised programme

---

## 1. Purpose

The initial baseline programme for Marrowbank, set at the start of development to give the workstreams a common timeline to FID and to first power. Dates are indicative and will be refined as consents, grid, and supply chain firm up.

## 2. Key milestones (initial baseline)

| Milestone | Initial target |
|---|---|
| Development consent (DCO) application submitted | 2026 |
| DCO granted | 2027 |
| Final Investment Decision | Q1 2026 |
| Grid energisation (connection available) | per initial offer |
| Onshore + offshore construction | 2027–2029 |
| **Target commercial operations date (COD)** | **2029** |

## 3. Assumptions

- A grid connection broadly aligned with a 2029 operations date.
- A consenting timeline (EIA + examination) that supports a DCO grant in time for a 2027–2029 build.
- Turbine delivery aligned with the build window.

## 4. Caveat

This is the **initial** programme. The two largest schedule risks are the consenting critical path (EIA, particularly ornithology, and examination) and turbine/vessel supply, both of which could move the COD later; conversely, a change to the grid connection could move it either way. **The COD of 2029 is a starting baseline and is expected to be revised** as these inputs resolve. A later, controlled revised programme will supersede this baseline.
